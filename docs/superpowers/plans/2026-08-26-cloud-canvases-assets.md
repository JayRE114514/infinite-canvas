# Cloud Canvases and Assets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Canvas snapshots and user Assets to Workspace-scoped PostgreSQL and private object storage while retaining responsive local editing.

**Architecture:** The server stores authoritative revisioned Canvas snapshots; the browser keeps a debounced local draft cache. Media bytes move directly between the browser/Worker and S3-compatible storage through immutable server-generated keys; PostgreSQL stores ownership and metadata.

**Tech Stack:** Fastify 5, TypeBox, Drizzle ORM, PostgreSQL JSONB, AWS SDK v3 S3 client, React 19, Zustand, localforage, TanStack Query, Vitest, Testcontainers.

**Spec:** `docs/superpowers/specs/2026-08-26-backend-platform-architecture-design.md`

## Global Constraints

- Depends on the completed identity/Workspace plan.
- Every Canvas and Asset query filters by the authorized path `workspaceId`.
- Canvas saves use `baseRevision`; stale writes return `409 revision_conflict` and never overwrite server data.
- Object keys are generated by the server and are never accepted from user input.
- Text Assets store text in PostgreSQL; image, video, audio, and file Assets store bytes in S3-compatible storage.
- Browser business state is a draft/cache after this plan, not the authoritative copy.
- Write tests and provide commands without executing tests, typechecks, builds, or browser automation.

```ts
export async function upload(workspaceId: string, file: File) {
  const intent = await createUploadIntent(workspaceId, {
    kind: kindFromMime(file.type), fileName: file.name, mimeType: file.type, byteSize: file.size,
  })
  const uploaded = await fetch(intent.uploadUrl, { method: 'PUT', headers: { 'Content-Type': file.type }, body: file })
  if (!uploaded.ok) throw new Error('素材上传失败')
  return completeUpload(workspaceId, intent.assetId)
}
```
