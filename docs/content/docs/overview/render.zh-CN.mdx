# Render 部署

<Callout type="warn">
当前后端分支暂不支持 Render 部署。
</Callout>

仓库现有 Render 配置只部署静态前端，没有提供 Fastify API、PostgreSQL 迁移发布步骤、后端 Secret，以及 `/api/auth` 与 `/api/v1` 所需的同源反向代理。

请不要使用原有 Deploy to Render 链接部署本分支，也不要把静态 Render 服务视为生产部署。后续部署计划会补齐 API 与反向代理拓扑。
