# Docker Deployment

<Callout type="warn">
Docker deployment is not available for the current backend branch. The tracked image and Compose files publish only the static frontend; they do not run the Fastify API or provide its same-origin reverse proxy.
</Callout>

## Current application image

Do not use the published image or build the root Dockerfile for this branch. They are missing the API process, PostgreSQL migration release step, backend secrets, and `/api` proxy required for authentication and Workspace APIs. They are not a production deployment.

The later deployment plan will split or compose the web/API processes and define the reverse proxy. Until then, use the local development workflow in [Quick Start](/docs/overview/quick-start).

## Documentation image

The documentation in `docs/` is a separate Next.js standalone application with server capabilities.

```bash
cd docs
docker compose up -d
```

To build it from the current source:

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

The documentation container is independent of the unavailable main-application deployment described above.

## Optional analytics

The legacy static-only image has optional analytics configuration, but that image cannot run this backend branch. No analytics are enabled by default:

| Variable | Description |
| --- | --- |
| `ANALYTICS_GA4_ID` | Google Analytics 4 measurement ID (`G-XXXX`) |
| `ANALYTICS_BAIDU_ID` | Baidu site ID, the hash after `hm.js?` |

```yaml
services:
  app:
    image: ghcr.io/basketikun/infinite-canvas:latest
    ports:
      - "3000:3000"
    environment:
      ANALYTICS_GA4_ID: G-XXXXXXXXXX
      ANALYTICS_BAIDU_ID: e8263761cc5c32f5f7a855b8203b965a
```

SPA route changes automatically report page views to enabled providers. Only configure analytics IDs on sites you control, and do not commit them to the repository.
