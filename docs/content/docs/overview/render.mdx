# Deploy on Render

<Callout type="warn">
Render deployment is not available for the current backend branch.
</Callout>

The tracked Render configuration deploys only the static frontend. It does not provide the Fastify API, PostgreSQL migration release step, backend secrets, or the same-origin reverse proxy required for `/api/auth` and `/api/v1`.

Do not use the existing Deploy to Render link for this branch or treat a static Render service as a production deployment. The later deployment plan will supply the API and reverse-proxy topology.
