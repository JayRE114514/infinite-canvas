# ADR 0003：所有可执行插件仅由项目所有者维护

状态：Accepted

不同官方 API 与中转平台存在模型 ID、请求参数、轮询协议和返回格式差异，因此上游接入通过 Provider Adapter 隔离。所有会在浏览器、API 或 Worker 内执行代码的扩展——包括 Provider Adapter、画布节点插件和远程节点脚本——只能由项目所有者编写、审查并随版本或所有者控制的注册表发布。

普通用户只能选择已发布能力并提供非执行配置，不能通过 URL、上传文件、npm 包、数据库脚本或远程模块安装任意第三方执行代码。当前源码中的旧 URL 节点插件入口属于发布前必须禁用或移除的未发布遗留能力。

后果：模型能力使用明确 schema 表达，平台按适配器版本记录任务；新增中转站不会把条件分支散落到画布 UI 或共享请求客户端。第三方开发者仍可 fork 和修改 MIT 源码，但不能把代码动态注入平台托管实例。
